# 品位关（这件事值不值得做）

## 口径：本关没有语料支撑

和 `pre_submission_rejections.md` 一样，这一关是**判断层**，不是证据层。全部内容为评审经验推演，不得包装成统计结论。

语料为什么支撑不了品位：

| 字段 | 实际内容 | 能否测品位 |
|---|---|---|
| `comments`（48,422 条） | 缺陷 | ✗ |
| `strengths`（11,203 条） | 客套与完成度（"well written" 出现 151 次） | ✗ |
| `editor_summary`（1,361 篇，中位 192 字符） | 操作指令（改什么），不含价值判断 | ✗ |

这套语料记录的是**缺陷与流程**，不是**价值判断**。所以本关只能靠提问，不能靠查库。

---

## 这一关解决什么

七关问的是「会不会被打」，品位关问的是「**在被审之前，它值不值得存在**」。

顺序错了会付出代价：把一个不值得做的题目打磨到没有技术缺陷，结果是「挑不出毛病，但没人需要」。

---

## 六问

### 1. 置换测试 —— 谁的行为会变

**问**：这个结论如果明天被证伪，谁会改变做法？

不是「谁会感兴趣」，是「谁的行为会变」。研究者的兴趣不是受众，决策者的动作才是。

- **命中**：说不出任何具体的决策点。所有人听完都会说「有意思」，然后继续做原来的事。
- **过法**：能点出 1–2 个具体决策（某个管理规程、某个模型参数、某个临床路径、某个理论的取舍）。
- **追问**：如果这个结论十年内没人用，它还有存在价值吗？（有=学科基础设施；没有=自我循环）

### 2. 缺口 vs 重构 —— 填洞还是换视角

**问**：你的贡献是「补了一个没人填的洞」，还是「让人换个方式看这件事」？

- **填洞**：文献里有人说「这里缺数据」，你补了。价值真实，但天花板是「这条线更完整了」。
- **重构**：你让人重新描述这件事——新的对照、新的尺度、新的机制假设、新的边界条件。
- **命中**：立项理由只有「尚未研究」「研究较少」「缺乏系统研究」。
- **过法**：能说出这句话——「在此之前，大家默认 X；本研究说明 X 不成立，或只在 Y 条件下成立」。
- **追问**：如果本文的结论成立，领域里哪一句教科书表述需要改？

### 3. 最近三篇测试 —— 数据还是看法

**问**：相对最近的三篇工作，你多出来的是「更多数据」还是「不同的看法」？

**操作**（必须落到纸面，不能只在心里想）：

1. 写下三篇最接近工作的 DOI
2. 每篇一句「它做了什么」
3. 每篇一句「我多做了什么」

- **命中**：三句「我多做了什么」里，两句以上是「样本更大 / 覆盖更广 / 时间更长 / 分辨率更高」。
- **过法**：至少一句是「它认为 X，我认为非 X」，并且能说出来为什么。
- **引用检索陷阱**：如果三篇里有一篇是同一课题组的前作，这一问的权重加倍——审稿人几乎一定会问「what is new here」。

### 4. 尺度匹配 —— 投入与问题分量

**问**：投入的资源、时间、人力，配得上这个问题的分量吗？

两种失衡，方向相反：

| 失衡 | 表现 | 典型评语 |
|---|---|---|
| 大炮打蚊子 | 方法极重，问题极轻 | 「为了一个几乎显然的结论做了三年实验」 |
| 弹弓打大象 | 问题极重，证据极轻 | 「用两个点位回答全球规律」 |

- **命中**：任一方向。
- **过法**：能用一句话说明「**为什么这个问题必须用这个规模**」——不是「我们恰好有这个平台」，而是问题本身要求这个尺度。

### 5. 承诺与交付 —— 差几层

**问**：标题和摘要承诺的层次，结论实际到达了哪一层？

三层：**现象**（描述）→ **机制**（解释）→ **框架**（改变提问方式）。

**操作**：把标题里的动词圈出来，对照结论的实际强度。

| 标题用词 | 承诺层次 |
|---|---|
| `drives` / `determines` / `causes` | 机制 |
| `shapes` / `structures` / `governs` | 机制偏框架 |
| `is associated with` / `covaries with` | 现象 |
| `rethinking` / `beyond` / `towards` | 框架 |

- **命中**：标题在框架层，结论在现象层。
- **过法**：每一层的落点都能指到具体图表；指不到的降级。
- **注意**：降级标题不会削弱论文，反而会让审稿人觉得作者清楚自己在做什么。反过来，抬高层级是最常见的自伤。

### 6. 零结果测试 —— 如果什么都没发现

**问**：如果结论是零，这个研究还值得做吗？

- **命中**：整个设计只有在「有显著效应」时才有意义。零结果既不能发表，也不能回答任何问题。
- **过法**：零结果本身能排除一个流行假设，或能界定效应的上界/下界。
- **追问**：审稿人问「如果你的假设不成立，这篇论文还剩下什么？」时，你有答案吗？

## 怎么输出

**不要打分。** 打分暗示了不存在的精度。给三档判断：

| 档 | 判据 | 含义 |
|---|---|---|
| **站得住** | 六问都能答，且第 2、3 问有明确答案 | 可以进入第 0 关与七关 |
| **需要重铸** | 第 2、3 问答不出，但第 1、4、5、6 问能答 | 问题存在，框架错了 |
| **不该做** | 第 1 或第 6 问失败 | 没有受众，或没有零结果价值 |

输出模板：

```
## 品位判断

**结论**：站得住 / 需要重铸 / 不该做

- 置换测试：…（能改变的具体决策 / 无）
- 缺口 vs 重构：…（填洞 / 重构 / 说不清）
- 最近三篇：…（列出三篇 + 增量类型）
- 尺度匹配：…（匹配 / 大炮打蚊子 / 弹弓打大象）
- 承诺与交付：…（标题层 vs 结论层）
- 零结果测试：…（有/无价值）

**重铸方向**（仅"需要重铸"时给）：换问题 / 换尺度 / 换对照 / 换受众
```

重铸方向要具体，不能写「建议进一步聚焦」这种话。

## 与七关的关系

```
品位关失败  →  七关的修补没有意义（把不值得做的题目打磨到没有技术缺陷）
品位关通过  →  七关才开始有用
```

两者不能互相替代：

- 只过品位关、不过七关：想法好，但会被技术细节打死
- 只过七关、不过品位关：挑不出毛病，但没人需要

## 常见误用

**把「有趣」当品位**
「这个现象很有意思」是感受，不是判断。要问的是「谁会因此改变做法」。

**把「新」当品位**
没用过的方法、没采过的样点、没做过的系统，都是新，但不等于有价值。新是必要条件，不是充分条件。

**把「能发表」当品位**
能发表只说明过了某本刊的门槛，说明不了这件事值得做。顶刊也有大量「正确但无关紧要」的论文。

**用本关替代决定**
本关给的是判断和理由，不是资助或接收决定。决定权在评审人。

## 诚实性

- 本关全部为判断，**无对应语料**，引用时不得与带 id 的语料证据并列
- 六问是启发式，不是充分条件；六问全过也可能是个平庸的题目
- 第 2、3 问最容易被自我说服，建议找一位不同领域的同事做盲测
