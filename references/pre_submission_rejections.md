# 桌拒风险（送审前就会死的那一类）

## 口径：这一节没有语料支撑，先读这段再往下看

`data/*.jsonl` 里的 1494 篇，全部是**已经通过编辑初筛、送出去外审**的稿子。桌拒的稿子不进库。所以：

- 语料能告诉你「进了外审之后会被怎么打」
- 语料**不能**告诉你「什么样的稿子根本进不了外审」

这是结构性缺口，不是数据缺陷。七关审的是**能不能扛住审稿人**；这一节审的是**能不能见到审稿人**。两件事的判据不一样，别混着用。

下面除明确标 `【语料】` 的部分，都是 `【判断】`——评审经验推演，不装成数据。

---

## 唯一的残余证据：漏网的适配性问题

虽然桌拒样本缺失，但有漏网的。有些稿子本该在初筛被拦，还是送审了，审稿人替编辑把话说出来了。全库检索期刊适配性关键词（`not appropriate for` / `out of place` / `better suited` / `specialist journal` / `incremental` / `too narrow` / `limited novelty` 等）：

【语料】

| | 篇数 | 占 1492 篇 |
|---|---:|---:|
| 出现任何严重级别的适配性表述 | 116 | 7.8% |
| 其中被列为 major | 52 | 3.5% |

major 意见按刊分布：EL 41 条 / NEE 13 条。

**怎么读这个数**：这是关键词代理，不是人工编码，会混入少量非适配性语境——**用它的量级，别用它的精确值**。它的意义在于证明：期刊适配性不是编辑的独角戏，审稿人会独立得出同一结论，而一旦得出基本等于死刑（这类意见几乎不给修的机会，诉求多为「换个刊」而非「改一版」）。

【语料】典型原句：

- "throughout reading the manuscript I felt like this is out of place for Nature Ecology & Evolution"
  → 诉求：Consider a more specialized journal or strengthen broad significance. — `10.1038/s41559-024-02575-6`
- "the manuscript is better suited for more of a specialist journal"
  → 诉求：Develop a more sophisticated framework or target a specialist journal. — `10.1111/ele.13713`
- "the novelty is incremental" / "at most is incremental" — `10.1038/s41559-024-02463-z` / `10.1038/s41559-025-02773-w`
- "In essence, [they] reproduce results from (Forzieri et al., 2022), in that they use the same method and datasets"
  → 诉求：Demonstrate a clear advance beyond Forzieri et al. 2022. — `10.1038/s41559-024-02631-1`
- "the findings do not really allow groundbreaking new concepts" — `10.1038/s41559-025-02773-w`

注意这几条的共性：**它们攻击的不是数据或方法，是"这篇稿子该不该存在"**。这种攻击没有技术性回应能接住。

## 六类桌拒风险（编辑视角）

每一类给：编辑看到什么就毙 → 你的自查问句。全部为 `【判断】`。

### 1. 期刊适配（scope fit）

编辑初筛只问一件事：**这篇稿子的读者是不是我们的读者**。EL 是广义生态学，NEE 是进化+生态并要求跨类群的广义意义，两者都明确排斥「只有本子系统专家会读」的稿子。

- 自查：把摘要给一个不做你这个系统的同行看，他会不会问「那又怎样」？
- 自查：如果只能投一个专业刊，损失的是什么？答不出来说明你没有广义读者。
- 高危信号：标题/摘要承诺一般机制，研究对象却是单一物种/单一位点（衔接第七关 generality）。

### 2. 增量不足（incrementality）

不是「不新」，是**「相对最近的某篇，新得不够」**。编辑会直接想起领域内的对标论文。

- 自查：一句话说清「相对 X（具体一篇，作者+年份），本文新在 Y」。说不出来就还没到投稿。
- 自查：如果对手组的上一篇已经做了 80%，你的 20% 撑得起这个刊吗？
- 高危信号：用新系统重复旧结论；用新方法复现旧结果；综述只是把已有观点重排。

### 3. 过度承诺（over-claim 在标题和摘要）

编辑不读方法，只读标题、摘要、图和结论。**这三处一旦有一处超出数据，初筛就危险**，因为编辑没有义务替你核实，只会判断「这看着像在吹」。

- 自查：标题里每个名词，正文都有对应的数据吗？
- 自查：摘要最后一句的强度，和结果章节最强的那条证据对得上吗？
- 高危信号：标题用 `global` / `universal` / `drives` / `determines`，数据是一个区域或一个相关分析。

### 4. 编辑自己就能看出的硬伤

有些问题不需要外审：样本量明显不够、缺对照、n=1、统计方法与数据结构明显不匹配、图不可读。**编辑本人多半是活跃研究者，这些他看得出来。**

- 自查：把方法和图单独抽出来给一个不熟悉你课题的同行，5 分钟内他能指出几个问题？
- 自查：有没有一个「如果我是编辑，我会觉得作者没想清楚」的地方？

### 5. 合规与格式

这一类的特点是**与科学质量无关，但能直接终止流程**：伦理审批缺失或不完整、动物处理说明不足、数据/代码可得性声明与期刊政策冲突、作者贡献声明不清、篇幅/格式不符合文章类型。

【语料】残余证据（说明这些事真的会在评审中被抓，且杀伤力不小）：

- "Provide the full ethical review board name and the measures for consent, confidentiality and data protection." — `10.1038/s41559-023-02037-5`
- "State ethics approvals and justify or shorten the food deprivation." — `10.1038/s41559-025-02737-0`
- "Clarify and correct the author contributions statement." — `10.1038/s41559-024-02404-w`

- 自查：伦理批号、批准机构全称、知情同意、动物福利时长，逐项写全了吗？
- 自查：数据声明里承诺的东西，真的已经在库里了吗（还是「will be available upon acceptance」式的空头支票）？

### 6. 类型错配（研究型 vs 综述/观点型）

综述投研究刊、观点文投需要原始数据的刊、方法文投要求生物学发现的刊。**编辑一眼就能判**，且通常不再送审。

- 自查：这篇文章的类型，和期刊的 article type 列表对得上吗？
- 自查：如果是综述，它提供了新框架还是只做了文献汇总？

## 与七关的关系

```
第 0 关（本节）  →  能不能见到审稿人
第 1–7 关        →  见到之后能不能活下来
```

**审基金申请书时第 0 关的等价物**：这不是「期刊适配」，而是「**这个题目在这个资助渠道、这个评审组眼里值不值得给钱**」。判据换成：是否落在该基金的优先资助方向、是否符合该学部的资助口径、题目的重要性是否在评审组的知识范围内可判断。基金的第 0 关语料完全没有覆盖，只能靠人工判断，**别用语料里的百分比冒充**。

## 输出约定

第 0 关命中时，输出必须与七关的弱点分开，并明确标注风险等级：

```
### 第 0 关 · 桌拒风险（送审前）
- 命中：期刊适配 / 增量不足
- 为什么会在初筛被拦：…
- 【判断】此节无对应语料，依据为编辑初筛逻辑推演
- 建议：投 A 刊前必须先解决 X；否则改投 B 刊或补 Y
```

**不要把第 0 关的结论包装成语料证据。** 这一节的全部价值在于它敢说「这里我没数据」。
